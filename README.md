# ZapRecipe – AR Cooking Guide

ZapRecipe is an Android-based augmented reality (AR) application developed using Unity and Vuforia Engine. It provides interactive, step-by-step cooking instructions by recognizing the packaging of selected food products through a mobile camera.

The application aims to make cooking more engaging and accessible by combining augmented reality with visual recipe guidance.

## Features

- **Marker-Based AR Recognition:** Recognizes selected product packaging using Vuforia Engine.
- **Interactive Recipe Instructions:** Displays step-by-step cooking guidance for supported products.
- **Cooking Timer:** Includes a timer to assist with cooking steps.
- **3D Model Interaction:** Supports interactive 3D models within the AR experience.
- **Android Support:** Designed to run on compatible Android devices.

## Supported Products

- Maggi Double Masala
- Bru Coffee
- DiSano Pasta

## Technologies Used

- Unity 6
- C#
- Vuforia Engine 11.4.4
- Android

## How It Works

1. Launch the application on a compatible Android device.
2. Point the device's camera at a supported product package.
3. Allow Vuforia to recognize the image target.
4. View the corresponding recipe instructions in augmented reality.
5. Follow the displayed steps and use the cooking timer where required.

## Project Structure

- `Assets/` – Scenes, scripts, models, images, and other application assets.
- `Packages/` – Unity package dependencies, including Vuforia Engine.
- `ProjectSettings/` – Unity project configuration.
- `QCAR/` – Supporting resources associated with the AR setup.

## Installation and Setup

1. Clone or download this repository.
2. Open the project using Unity Hub with a compatible Unity Editor version.
3. Allow Unity to resolve the project dependencies.
4. Ensure Vuforia Engine is configured correctly.
5. Configure the Android build settings and connect a compatible device.
6. Build and run the application.

**Note:** Vuforia configuration, image targets, and Android build requirements may need to be verified before running the project on another device.
